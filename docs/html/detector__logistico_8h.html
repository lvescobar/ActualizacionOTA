Descripción detallada

Detector de anomalias con regresion logistica para el ESP32.

No depende de Arduino: solo usa <math.h>. Por eso se puede probar en un PC normal con g++ antes de subirlo al ESP32.

Idea general:

  1. Calibracion: con las primeras 30 muestras se calcula la media y la desviacion estandar de cada variable (temperatura y valor tactil).
  2. Cada muestra se convierte a "desviaciones estandar": z = (x - media) / desviacion.
  3. Caracteristicas: |z| de cada variable (limitado a 10).
  4. Regresion logistica: p = sigmoide(SESGO + W_TEMP*|z_temp| + W_TACTO*|z_tacto|). p es la probabilidad de anomalia. Si p > 0.5 es anomalia.
Nota
La regresion logistica es SUPERVISADA: sus pesos se entrenan en el PC con entrenamiento/entrenar_logistica.py. El ESP32 solo calcula la prediccion.
